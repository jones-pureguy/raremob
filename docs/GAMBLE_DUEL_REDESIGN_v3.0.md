# GAMBLE DUEL 리디자인 기획서 v3.0

> **한 줄 컨셉**: "로열 스트레이트 플러시가 난무할 수 있는 하이랭크 포커 대전"

---

## 1. 핵심 설계 철학

- **베팅이 본 게임이다.** 카드 딜링 과정에서 정보를 읽고, 상대와 나의 최상위 패 가능성을 예측하고, 칩을 걸어 승부하는 것이 핵심 재미.
- **게임 플레이는 확인 사살이다.** 베팅에서 판단한 최상위 패를 실제로 만들어내는 실행력 싸움.
- **블라인드 베팅의 긴장감.** Phase 1 전체가 상대 카드를 모르는 블라인드 상태. 1장씩 추가될 때마다 내 패의 가능성이 변하고, 그에 따라 베팅 판단이 달라진다.
- **레이즈 금액을 직접 선택하는 전략.** 소/중/대 레이즈를 선택하여 판돈의 크기를 조절. "좋은 패지만 대 레이즈하면 상대가 폴드할 거야. 중으로 걸어서 따라오게 만들자" 같은 전략적 사고.
- **상대 카드 공개의 충격.** Phase 2에서 양쪽 20장이 처음 공개되는 순간이 가장 큰 드라마. Phase 1에서 자신만만하게 올렸는데 상대 패를 보고 "아차..." 하는 반전.
- **귀속 공개는 드라마 연출.** 마지막 10장이 팍팍팍 배분되는 순간은 베팅 없이 순수한 드라마. 예상대로 유리해졌는지, 반전이 생겼는지 확인하는 순간.
- **상대 플레이가 실시간으로 보인다.** 게임 중 상대 그리드가 완전 공개. 상대가 헤매는 모습, 빠르게 완성하는 모습이 심리적 압박과 재미를 만든다.
- **3패 2승.** 최상위 3개 패를 비교하여 2승 이상이면 승리. 포트폴리오 전략 + 실행 변수.
- **RF+라는 역전 가능성.** 상대가 로열 플러시를 가져도 드래그 순서(10→J→Q→K→A)를 맞추면 RF+로 이길 수 있다.

## 3. Phase 상세 설계

### Phase 0: 카드맵 + OUT 카드

**화면 구성:**
52장을 수트별 4줄 × 13장으로 표시. 각 카드는 세로 직사각형 형태(숫자 + 수트 마크).

**OUT 카드 연출:**
1. 카드맵에서 1장이 dim 처리 (약 1초) → 내 OUT 카드
2. 1장 더 dim 처리 (1초) → 상대 OUT 카드
3. OUT 카드 숫자로 선/후 결정 (높은 숫자가 선)
4. 결과 표시: "★" 마크가 선 플레이어 쪽에 표시

**소요 시간:** 약 3초

---

### Phase 1-A: 15장 블라인드 배분 → 베팅

**동작:**
1. 내 카드맵에 15장 골드 테두리 표시 (공개)
2. 상대 카드맵에 오버레이 "OPPONENT 15 CARDS / HIDDEN" (비공개)
3. 딜링 연출 (약 4~5초)
4. 베팅 시작

**이 시점 정보:**
- 내 카드 15장 공개
- 상대 카드 15장 비공개 (뒷면)
- 남은 미배분 20장

**베팅 성격:** 블라인드 베팅. 내 패만 보고 자신감으로 승부.

---

### Phase 1-B: +3장 블라인드 추가 → 베팅

**동작:**
1. 내 카드맵에 +3장 골드 테두리 추가 (총 18장)
2. 상대 오버레이 "OPPONENT 18 CARDS / HIDDEN" 업데이트
3. 베팅 시작

**이 시점 정보:**
- 내 카드 18장 공개
- 상대 카드 18장 비공개
- "3장 추가로 내 패 가능성이 어떻게 변했나?" 판단

---

### Phase 1-C: +2장 블라인드 추가 → 베팅

**동작:**
1. 내 카드맵에 +2장 골드 테두리 추가 (총 20장)
2. 상대 오버레이 "OPPONENT 20 CARDS / HIDDEN" 업데이트
3. 베팅 시작

**이 시점 정보:**
- 내 카드 20장 공개
- 상대 카드 20장 비공개
- "20장이면 최상위 패 윤곽이 거의 잡혔다. 자신 있다!" 또는 "별로네..."

---

### Phase 2: 양쪽 20장 공개 → 베팅 (FINAL BETTING)

**동작:**
1. 상대 카드맵 오버레이 걷힘 (fade out) → **상대 20장 최초 공개!**
2. 상대 카드 20장 순차 공개 연출 (약 3~4초)
3. 미배분 10장에 unassigned 하이라이트 (양쪽 카드맵)
4. 베팅 시작

**상대 카드 공개 순간 — 핵심 드라마 포인트:**
- Phase 1 전체에서 블라인드였던 상대 20장이 처음으로 공개
- "아 상대한테 스페이드 A,K,Q가 갔었네..." 충격 또는 안도
- Phase 1에서 자신만만하게 올렸는데 상대 패를 보고 "아차..." 하는 반전

**이 시점 정보:**
- 양쪽 20장 완전 공개
- 남은 미배분 10장 (뭔지 양쪽 다 알고 있음)
- 누구한테 갈지만 미정

**베팅 성격:** 마지막 베팅. 양쪽 패를 비교하고 최종 판단.

---

### Phase 3: 마지막 5+5장 귀속 공개 (베팅 없음)

**이 Phase의 본질:**
남은 10장이 한 장씩 누구한테 가는지 공개된다. **베팅은 이미 끝났으므로** 순수한 드라마 연출.

**귀속 공개 연출 (약 5~7초):**
1. 미배분 10장이 카드맵에서 하이라이트 (깜빡임)
2. 한 장씩 **팍-팍-팍** 골드 또는 시안 테두리로 바뀜
3. 한 장당 약 0.5~0.7초 간격
4. 바뀌는 순간 해당 카드 셀에 글로우 이펙트 + 짧은 효과음
5. 귀속되면 반대쪽 카드맵에서 해당 카드 unassigned 제거

**감정 흐름:**
- "♠10 제발 나한테..." → 골드 테두리! → "왔다!!"
- 예상대로 유리해졌는지, 반전이 생겼는지 확인하는 순간
- 이미 베팅이 끝났기 때문에 순수한 흥분/긴장만 남음

**공개 완료 → 바로 게임 시작**

---

### Phase 4: 게임 플레이 (120초)

**전환 연출:**
1. 카드맵 축소/사라짐
2. 양쪽 5×5 그리드 등장 (상대 그리드 축소, 내 그리드 풀사이즈)
3. 25장 랜덤 배치
4. 120초 카운트다운 시작

**규칙:**
- 10 이상 원페어부터 유효 패 (원래 규칙 복원)
- **최상위 3패 비교, 2승 이상이면 승리**
- 최대 5패
- NO MORE MOVES 시 자동 종료

**상대 그리드 완전 공개:**
- 상대의 5×5 그리드가 축소 크기로 상단에 표시
- 실제 카드가 다 보임 (뒷면 아님)
- 상대 패 완성 시 업데이트
- 상대 패 완성 시 어떤 패를 만들었는지 표시

**스코어보드:**
- 양쪽 최대 5패 표시
- Top 3에만 승패 비교 + 왕관 표시
- 4~5행은 패 이름만 (승패 무관)

---

### Phase 5: 결과 판정 + 칩 정산

- 최상위 3패 비교, 2승 이상이면 승리
- RF+ > RF 룰 유지
- 칩 정산 (pot 기반)
- 게임 전/후 칩 변동 표시 (양쪽 모두)
- 재대결 / 로비 선택

## 5. 베팅 UI 구조

### 카드맵 위치
- 상대 카드맵: 화면 상단 고정 (absolute, top: 12px)
- 내 카드맵: 화면 하단 고정 (absolute, bottom: 12px)
- 베팅 영역: 정확히 가운데 (absolute, top: 50%, transform: translateY(-50%))
- 베팅 패널이 나타나고 사라져도 카드맵 위치 불변

### 베팅 버튼

**내 턴 — 아직 레이즈 안 했을 때:**

첫 턴 (상대 RAISE 없음):
  [SKIP] [RAISE 소+{N}] [RAISE 중+{N}] [RAISE 대+{N}] [FOLD]

상대가 RAISE 후 (리레이즈):
  [CALL +{매칭액}] + 상대 금액 이상 RAISE만 표시 + [FOLD]
  예: 상대 소(3) → [CALL +3] [RAISE 소+6] [RAISE 중+11] [RAISE 대+18] [FOLD]
  예: 상대 중(8) → [CALL +8] [RAISE 중+16] [RAISE 대+23] [FOLD]
  예: 상대 대(15) → [CALL +15] [RAISE 대+30] [FOLD]

**내가 이미 레이즈 했고 상대가 리레이즈:**
  [CALL +{매칭액}] [FOLD]

**상대 턴:**
  "상대방 베팅 중..." + 모든 버튼 비활성

### 리레이즈 규칙
- 상대 레이즈 금액 이상으로만 리레이즈 가능
- 각자 Phase당 최대 1회 레이즈
- CALL 금액 = 상대 레이즈 금액 그대로 매칭
- 리레이즈 비용 = 매칭(상대 금액) + 추가(내 레이즈 금액)

### 상대 액션 표시
상대 RAISE/CALL/SKIP/FOLD 시 화면 중앙에 오버레이:
- RAISE: "상대방 RAISE 중 +{금액}" (노란색)
- CALL: "상대방 CALL" (초록)
- SKIP: "상대방 SKIP" (흰색)
- FOLD: "상대방 FOLD" (빨강)

### Phase 배너
- Phase 1-A: "1st BETTING"
- Phase 1-B: "2nd BETTING"
- Phase 1-C: "3rd BETTING"
- Phase 2: "FINAL BETTING"

### 레이즈 인디케이터
각 Phase의 소/중/대 금액을 표시:
  [3] → [8] → [15]  (Phase 1-A)
  [소]   [중]   [대]

상대 레이즈 이하 금액은 dim 처리.

### POT 표시
원형 디스플레이 + 칩 아이콘 + 금액 + "POT" 라벨.
금액 변경 시 펄스 애니메이션.

## 6. 베팅 구조 (확정)

### 레이즈 금액 테이블

```
              소     중     대
Phase 1-A:    3      8     15
Phase 1-B:    5     12     25
Phase 1-C:    8     20     40
Phase 2:     15     40    100
```

### 베팅 규칙

- 각 Phase에서 각자 최대 1회 레이즈
- 레이즈 금액은 소/중/대 중 선택
- 리레이즈 시 상대 레이즈 금액 이상만 가능
- 양쪽 SKIP → Phase 종료 (pot 변동 없음)
- 한쪽 RAISE → 상대 CALL/RAISE/FOLD
- 한쪽 RAISE → 상대 RAISE → 선 CALL/FOLD (더 이상 레이즈 불가)

### 칩 부족 시 (올인)

- RAISE/CALL 금액 > 내 잔여 칩 → ALL-IN (잔여 칩 전액)
- ALL-IN 후 이후 Phase 베팅 스킵
- 버튼 표시: "ALL-IN +{잔여칩}"

### 베팅 타이밍

```
Phase 1-A/1-B/1-C 턴당: 15초
Phase 2 턴당: 20초
타임아웃: 자동 CALL
```

### 시뮬레이션

**소극적 게임:**
```
초기 pot: 2
1-A: 양쪽 SKIP → pot 2
1-B: 선 소(+5) → 후 CALL(+5) → pot 12
1-C: 양쪽 SKIP → pot 12
2:   선 소(+15) → 후 CALL(+15) → pot 42
```

**공격적 게임:**
```
초기 pot: 2
1-A: 선 중(+8) → 후 CALL(+8) → pot 18
1-B: 선 대(+25) → 후 CALL(+25) → pot 68
1-C: 선 대(+40) → 후 CALL(+40) → pot 148
2:   선 대(+100) → 후 CALL(+100) → pot 348
```

**혼합 (리레이즈):**
```
초기 pot: 2
1-A: 선 소(+3) → 후 대(매칭3+15=+18) → 선 CALL(+15) → pot 38
1-B: 양쪽 SKIP → pot 38
1-C: 선 중(+20) → 후 CALL(+20) → pot 78
2:   선 대(+100) → 후 FOLD → 선 승리, pot 78
```

**밸런스 레인지:** 2 ~ 약 400+ (평균 50~150 예상)

## 11. 핵심 드라마 포인트

### 1. 블라인드 베팅의 자신감 (Phase 1 전체)
내 패만 보고 상대는 모르는 상태에서 4번의 베팅 기회.
1장씩 추가될 때마다 내 패의 가능성이 변하고 판단이 달라진다.
"스페이드 7장 왔어, 레이즈 대!" → 3장 추가... "♠10 안 왔네. 이번은 스킵."

### 2. 상대 카드 최초 공개 (Phase 2 시작)
Phase 1 전체에서 블라인드였던 상대 20장이 처음으로 공개.
"아 상대한테 스페이드 A,K,Q가 갔었네..." 충격 또는 안도.
Phase 1에서 자신만만하게 올렸는데 상대 패를 보고 "아차..." 하는 반전.

### 3. 레이즈 크기 선택의 전략
소/중/대를 선택하는 것 자체가 전략.
"좋은 패지만 대로 가면 상대가 폴드. 중으로 걸어서 따라오게 만들자."
"상대가 소로 걸었어. 리레이즈 대로 눌러볼까?"

### 4. 귀속 공개의 드라마 (Phase 3)
베팅 끝난 후 남은 10장이 팍팍팍 배분.
"♠10 제발 나한테..." 하는 순간.
이미 판돈이 결정된 상태라 순수한 긴장감만 남음.

### 5. 실시간 관전 드라마 (Phase 4)
상대가 자신만만하게 베팅했는데 실제 게임에서 헤매는 모습이 보임.
3패 2승이라 "상대가 1패 먼저 완성했지만 나머지 2패에서 이기면 돼" 전략.

### 6. RF+ 역전
상대 로열 플러시를 RF+로 뒤집는 순간.
큰 판돈을 빼앗는 최고의 드라마.

## 12. 게임 규칙 모달 텍스트

```
[승패 규칙]
카드를 25장씩 나눠 갖고 플레이해 만든 최상위패 3개로 승부
*중요규칙 : 10미만의 ONE PAIR 패도 패로 인정

[베팅 단계]
25장의 카드를 나눠 갖는 동안 4 Phase 베팅 진행

Phase 1-A — 15장 배분. 내카드만 공개 후 1회 베팅
Phase 1-B — 3장 추가. 내카드만 공개 후 1회 베팅
Phase 1-C — 2장 추가. 내카드만 공개 후 1회 베팅
Phase 2 — 양쪽 20장 공개 후 최종 1회 베팅

[베팅 액션]
SKIP — 베팅 안함. 상대방이 SKIP시 베팅종료. 상대방 레이즈 가능.
CALL — 상대방 레이즈만 받고 베팅 종료.
RAISE — 소/중/대 중 선택하여 판돈을 올림. 리레이즈 시 상대 금액 이상만 가능.
FOLD — 모든 판돈을 잃고 게임 포기.
```
